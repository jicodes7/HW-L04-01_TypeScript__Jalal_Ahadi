# HW-L04-01 - TypeScript Expense Tracker

پیاده‌سازی کامل موارد خواسته‌شده:
- TypeScript و typeهای صریح برای Transaction / Wallet / Reminder
- ثبت درآمد و هزینه
- دسته‌بندی سفارشی
- Pie Chart و Line Chart با Recharts
- Redux Toolkit + Context API
- LocalStorage
- جستجو و فیلتر عنوان/مبلغ/تاریخ/دسته‌بندی
- Responsive UI با Tailwind CSS
- Reminder
- Multi Wallet و انتقال بین حساب‌ها
- Export CSV/PDF/JSON و Import JSON

## اجرا
```bash
npm install
npm run dev
```
